## 🎯 Quick Start (5 minutes)

### Step 1: Deploy to Vercel
1. Go to [vercel.com](https://vercel.com)
2. Click "Sign up" and choose "Continue with GitHub"
3. Click "Import Project" or "New Project"
4. Select your repository: `usamawaleed83/Himalayan-Shilajit`
5. Configure:
   - **Framework Preset**: Next.js (auto-detected)
   - **Root Directory**: `.` (leave empty)
   - **Build Command**: `npm run build` (auto-detected)
   - **Output Directory**: `.next` (auto-detected)
6. Click "Deploy"

### Step 2: Your Site is Live!
- Vercel will automatically build and deploy your site
- You'll get a URL like: `https://himalayan-shilajit-xyz.vercel.app`
- The deployment takes about 2-3 minutes

## 🔄 Backend Integration (Optional)

Currently, your app uses **in-memory storage** which works perfectly for demonstration and testing. If you want to add the Express.js backend later:

1. Deploy backend to Render (see `deploy.md`)
2. Add environment variable in Vercel:
   ```
   NEXT_PUBLIC_API_URL=https://your-backend.onrender.com/api
   ```
3. Redeploy (automatic)
